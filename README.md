# Password Generator ULTRA PRO 🛡️

A secure, high-performance web application designed to generate ultra-secure passwords with advanced options and real-time strength evaluation.

## 🚀 Key Features
- **Cryptographically Secure:** Uses `crypto.getRandomValues()` for true cryptographic randomness.
- **Customizable Length:** Easily adjust password length from 6 up to 64 characters.
- **Character Options:** Select Uppercase, Lowercase, Numbers, and Symbols.
- **No Duplicate Chars:** Optional constraint to prevent duplicate characters in the generated password.
- **Strength Meter:** Dynamic visual feedback showing password strength (Weak, Medium, Strong).
- **One-Click Copy:** Quickly copy generated passwords to the clipboard with smooth notification toasts.

## 🛠️ Technologies Used
- **HTML5 & CSS3** - Modern UI design with responsive layout and CSS variables.
- **JavaScript (ES6+)** - Core logic, Fisher-Yates shuffle algorithm, and Web Crypto API.
- **FontAwesome** - UI icons.
